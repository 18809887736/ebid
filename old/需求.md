# AVC/AGC 招标公告自动监控 — 项目需求

> 立项日期:2026-10-22(用户批准"立项通过")
> 建成日期:2026-10-23
> 状态:已交付运行

## 1. 背景与目标

用户从事电力行业 AVC(自动电压控制)/ AGC(自动发电控制)相关业务,需要及时掌握各大电力集团发布的 AVC/AGC 方面招标公告,以便参与投标。

**目标**:每天自动检查指定招标网站,发现 AVC/AGC 相关招标公告后,第一时间通知用户("发现后通知我们")。

## 2. 监控范围

### 2.1 网站清单(来源:readme.md)

| # | 网站 | 网址 | 覆盖情况 |
|---|------|------|---------|
| 1 | 国能E招 | http://www.chnenergybidding.com.cn/bidweb/001/001002/moreinfo.html | ✅ 静态 HTML 抓取:招标公告/非招标公告/变更公告 各前 3 页 |

## 3. 功能需求

| 编号 | 需求 | 实现 |
|------|------|------|
| R1 | 每天自动检查 2 次(招标公告白天陆续发布,多查减少漏报) | 定时任务 `avc-agc-bid-watch`,每天 08:30 / 14:30 |
| R2 | 发现新公告后自动通知 | 新公告(30 天内发布)自动发邮件,由脚本内置两段式确认完成 |
| R3 | 通知对象 | 1783602@qq.com(发送方:已授权的 agently 邮箱 ebaneban888@agent.qq.com) |
| R4 | 不重复通知 | site+标题 MD5 去重,存 `data/seen.json` |
| R5 | 首次运行建档不轰炸 | 基线模式:历史公告全部入库,只发一封激活摘要(近 14 天在发公告) |
| R6 | 站点失败不中断 | 单站点失败记录告警,其余站点结果照常处理;输出 RESULT: WARN 提示重试 |

## 4. 非功能需求 / 约束

- 华电站有瑞数(RiverSecurity)反爬,必须真实浏览器(ego-browser)访问,curl 不可用
- 大唐 cdt-ec.com 为 Vue SPA 且招标栏目需登录(用户名+密码+验证码),验证码无法无人值守,故采用其公开数据源犀维网替代
- 邮件日发送配额 50 封(agently 限制),当前每天最多 2 封,余量充足
- 定时任务仅在 Claude 应用打开时运行;关闭期间错过的检查在下次打开时补跑一次
- 国能E购若未来开放公开公告列表,可按 run_check.py 模式扩展第 4 站
